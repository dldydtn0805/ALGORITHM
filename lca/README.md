# LCA

트리에서 두 정점의 최소 공통 조상(LCA, Lowest Common Ancestor)을 빠르게 구하는 Java 구현 설명입니다.

대상 파일:

- [Main.java](./Main.java)

## LCA란?

LCA는 트리에서 두 정점 `u`, `v`의 공통 조상 중 가장 깊이가 깊은 정점을 뜻합니다.

예를 들어 어떤 정점의 부모가 계속 위로 이어질 때, 두 정점이 처음으로 만나는 가장 가까운 조상을 찾는 문제입니다.

이 문제는 여러 번의 질의를 빠르게 처리해야 할 때 자주 나오며, 보통 이진 점프(binary lifting) 방식으로 풀이합니다.

## 이 Java 파일이 하는 일

이 코드는 루트가 `1`인 트리를 입력받아 여러 개의 LCA 질의를 처리합니다.

흐름은 아래와 같습니다.

1. 정점 수 `N`과 `N - 1`개의 간선을 입력받아 트리를 만듭니다.
2. DFS로 각 정점의 깊이(`depth`)와 바로 위 부모(`parents[node][0]`)를 구합니다.
3. `parents[node][k]`에 `2^k`번째 조상을 저장하는 희소 배열을 채웁니다.
4. 질의마다 두 정점의 깊이를 맞춘 뒤, 가장 큰 점프부터 동시에 올려서 LCA를 찾습니다.

## 핵심 로직

### 1. 깊이와 직계 부모 구하기

`build(idx, prev)`는 루트 `1`에서 시작하는 DFS입니다.

- `depth[next] = depth[idx] + 1`
- `parents[next][0] = idx`

이 과정을 통해 각 정점의 깊이와 바로 위 부모를 기록합니다.

### 2. 희소 배열 만들기

`parents[node][k]`는 정점 `node`의 `2^k`번째 조상을 의미합니다.

예를 들어:

- `parents[node][0]`: 바로 위 부모
- `parents[node][1]`: 2칸 위 조상
- `parents[node][2]`: 4칸 위 조상

이 값이 준비되면 정점을 한 번에 여러 단계 위로 빠르게 올릴 수 있습니다.

코드에서 이 배열을 채우는 부분은 아래와 같습니다.

```java
for (int j = 0; j < MAX; j++) {
    for (int i = 1; i < N + 1; i++) {
        if (parents[i][j] != -1) {
            parents[i][j + 1] = parents[parents[i][j]][j];
        }
    }
}
```

핵심 점화식은 다음 한 줄입니다.

```text
parents[i][j + 1] = parents[parents[i][j]][j]
```

왜 이 식이 맞는지 순서대로 보면:

- `parents[i][j]`는 정점 `i`의 `2^j`번째 조상
- 그 정점의 `2^j`번째 조상을 다시 구하면
- 원래 정점 `i`에서는 총 `2^j + 2^j = 2^(j+1)`칸 위 조상이 됩니다

즉 의미는 다음과 같습니다.

- 2칸 위 조상 = 1칸 위 조상의 1칸 위 조상
- 4칸 위 조상 = 2칸 위 조상의 2칸 위 조상
- 8칸 위 조상 = 4칸 위 조상의 4칸 위 조상

예를 들어 어떤 트리에서:

- `parents[8][0] = 4`
- `parents[4][0] = 2`

라면,

```text
parents[8][1] = parents[parents[8][0]][0]
              = parents[4][0]
              = 2
```

즉 정점 `8`의 2칸 위 조상은 `2`가 됩니다.

이렇게 `parents[][0]`부터 시작해서 `parents[][1]`, `parents[][2]`를 차례대로 채워 두면, 나중에 정점을 위로 올릴 때 필요한 `2^j` 점프를 즉시 사용할 수 있습니다.

### 3. 두 정점의 깊이 맞추기

두 정점 `u`, `v`의 깊이가 다르면 더 깊은 쪽을 위로 올려 같은 높이로 맞춥니다.

코드에서는 깊이 차이를 이진수처럼 분해해서 필요한 `2^k` 점프만 적용합니다.

예를 들어 깊이 차이 `diff = 13`이면:

```text
13 = 1101(2) = 8 + 4 + 1
```

즉 아래 점프만 적용하면 됩니다.

- `2^3 = 8`칸 위
- `2^2 = 4`칸 위
- `2^0 = 1`칸 위

이렇게 하면 정확히 `13`칸 올라가므로 두 정점의 깊이가 같아집니다.

코드의 이 부분은 `diff`의 가장 작은 비트부터 하나씩 확인하는 방식입니다.

```java
int diff = depth[u] - depth[v];
for (int j = 0; diff > 0; j++) {
    if (diff % 2 == 1) u = parents[u][j];
    diff /= 2;
}
```

여기서 의미는 다음과 같습니다.

- `diff % 2 == 1`: 현재 비트가 `1`이므로 `2^j`칸 점프가 필요함
- `diff % 2 == 0`: 현재 비트가 `0`이므로 그 점프는 건너뜀
- `diff /= 2`: 다음 비트를 확인하러 이동

즉 `depth[u]`와 `depth[v]` 자체를 보는 것이 아니라, `depth[u] - depth[v]`를 이진수로 보면서 필요한 점프만 골라서 적용하는 것입니다.

왜 이 방식이 항상 맞는지는 모든 정수가 이진수로 유일하게 표현되기 때문입니다. 필요한 이동 거리 역시 `1`, `2`, `4`, `8` 같은 `2`의 거듭제곱 점프들의 합으로 정확히 만들 수 있습니다.

### 4. 같이 위로 올리며 LCA 찾기

깊이가 같아진 뒤에도 `u != v`라면, 큰 점프부터 확인하면서
`parents[u][k] != parents[v][k]`인 동안 둘을 함께 위로 올립니다.

마지막에는 두 정점의 바로 위 부모가 같아지므로 `parents[u][0]`이 LCA가 됩니다.

이 단계의 핵심은 "서로 다른 조상을 유지하는 가장 큰 점프를 먼저 적용한다"는 점입니다.

```java
for (int j = MAX - 1; j >= 0; j--) {
    if (parents[u][j] != -1 && parents[u][j] != parents[v][j]) {
        u = parents[u][j];
        v = parents[v][j];
    }
}
u = parents[u][0];
```

왜 큰 점프부터 봐도 되는 이유는 다음과 같습니다.

- `parents[u][j] == parents[v][j]`이면 `2^j`칸 위에서 이미 같은 조상을 만난다는 뜻이므로, 그 점프는 너무 큽니다.
- `parents[u][j] != parents[v][j]`이면 아직 LCA 아래에 있으므로, `2^j`칸만큼 안전하게 함께 올릴 수 있습니다.
- 큰 점프부터 가능한 만큼 적용하고, 남은 거리는 더 작은 `2^j` 점프로 처리하면 됩니다.

이 역시 이진 점프가 통하는 이유와 같습니다. 트리 위에서의 이동도 결국 `2^j` 단위 점프들의 조합으로 표현할 수 있으므로, 큰 점프부터 검사해도 LCA 바로 아래 위치까지 정확히 도달할 수 있습니다.

루프가 끝나면 `u`와 `v`는 서로 다르지만 바로 위 부모는 같은 상태가 됩니다. 그래서 마지막에 `parents[u][0]` 한 번만 더 올리면 최소 공통 조상이 됩니다.

## 시간 복잡도

- 전처리 DFS: `O(N)`
- 조상 테이블 구성: `O(N log N)`
- 질의 1회: `O(log N)`

질의가 여러 번 들어오는 트리 문제에서 효율적으로 사용할 수 있습니다.

## 실행 방법

```bash
javac lca/Main.java
printf "5\n1 2\n1 3\n2 4\n3 5\n3\n4 5\n2 4\n2 3\n" | java -cp lca Main
```

## 실행 예시

입력:

```text
5
1 2
1 3
2 4
3 5
3
4 5
2 4
2 3
```

출력:

```text
1
2
1
```

각 질의에 대해 두 정점의 최소 공통 조상을 한 줄씩 출력한 결과입니다.
