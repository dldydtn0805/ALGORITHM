# KMP

문자열에서 패턴이 등장하는 모든 위치를 찾는 KMP(Knuth-Morris-Pratt) 알고리즘의 Java 구현 설명입니다.

대상 파일:

- [Main.java](/Users/yongsoolee/Documents/GitHub/algorithm/kmp/Main.java)

## KMP란?

KMP는 문자열 검색 알고리즘입니다.

텍스트를 처음부터 끝까지 보면서 패턴과 비교하되, 불일치가 발생했을 때 이미 비교한 정보를 재활용해서 다시 처음부터 비교하지 않습니다.

이를 위해 패턴 내부의 접두사/접미사 정보를 담은 `pi` 배열(실패 함수)을 먼저 구한 뒤 검색에 사용합니다.

## 이 Java 파일이 하는 일

이 코드는 입력으로 문자열 두 줄을 받아 아래 작업을 수행합니다.

1. 첫 번째 줄을 전체 문자열 `text`로 읽습니다.
2. 두 번째 줄을 찾을 문자열 `pattern`으로 읽습니다.
3. `buildPi(pattern)`으로 접두사/접미사 정보를 계산합니다.
4. `kmp(text, pattern)`으로 패턴이 등장하는 모든 시작 위치를 찾습니다.
5. 등장 횟수와 각 위치를 1-based 인덱스로 출력합니다.

## 핵심 로직

### 1. `pi` 배열 만들기

`pi[i]`는 `pattern[0..i]` 구간에서 접두사이면서 접미사인 문자열의 최대 길이를 의미합니다.

예를 들어 패턴이 `ABABAC`이면 `pi` 배열은 다음과 같습니다.

```text
index:   0 1 2 3 4 5
pattern: A B A B A C
pi:      0 0 1 2 3 0
```

불일치가 발생했을 때 이 값을 이용하면, 패턴을 얼마나 건너뛸 수 있는지 빠르게 알 수 있습니다.

### 2. 텍스트에서 패턴 찾기

검색 과정에서는 텍스트 인덱스 `i`와 패턴 인덱스 `j`를 함께 이동합니다.

- 문자가 같으면 `j`를 증가시킵니다.
- 다르면 `j = pi[j - 1]`로 되돌아가며 비교를 이어갑니다.
- `j == pattern.length()`가 되면 패턴 하나를 찾은 것이므로 시작 위치를 저장합니다.
- 이후에도 겹치는 패턴을 찾기 위해 `j = pi[j - 1]`로 이어서 진행합니다.

## 시간 복잡도

- `buildPi(pattern)`: `O(M)`
- `kmp(text, pattern)`: `O(N)`
- 전체: `O(N + M)`

여기서 `N`은 텍스트 길이, `M`은 패턴 길이입니다.

## 실행 방법

```bash
javac kmp/Main.java
printf "ABABABA\nABA\n" | java -cp kmp Main
```

## 실행 예시

입력:

```text
ABABABA
ABA
```

출력:

```text
3
1 3 5
```

패턴 `ABA`가 텍스트에서 1, 3, 5번째 위치부터 시작한다는 뜻입니다.
