# Phi Function

오일러 피함수(`phi(n)`)를 계산하는 Java 파일 설명입니다.

대상 파일:

- [Main.java](./Main.java)

## 피함수란?

`phi(n)`은 `1`부터 `n`까지의 자연수 중에서 `n`과 서로소인 수의 개수를 구하는 함수입니다.

예를 들어 `phi(12) = 4`이고, `12`와 서로소인 수는 `1`, `5`, `7`, `11`입니다.

## 이 Java 파일이 하는 일

이 코드는 입력으로 자연수 `N`을 하나 받아서 `phi(N)` 값을 출력합니다.

`Main` 클래스의 흐름은 아래와 같습니다.

1. `BufferedReader`로 숫자 하나를 입력받습니다.
2. `phi(n)` 메서드에서 소인수분해를 이용해 피함수를 계산합니다.
3. 계산된 결과를 출력합니다.

## 핵심 로직

피함수는 서로 다른 소인수 `p`에 대해 아래 공식을 적용해서 구할 수 있습니다.

```text
phi(n) = n * (1 - 1/p1) * (1 - 1/p2) * ... * (1 - 1/pk)
```

코드에서는 이를 다음 방식으로 구현합니다.

- 처음에 `result = n`으로 둡니다.
- `2`부터 시작해서 `n`의 소인수를 찾습니다.
- 소인수 `p`를 찾으면 `result = result - result / p`를 적용합니다.
- 같은 소인수는 한 번만 반영하도록 `n`을 계속 나눠 줍니다.
- 마지막에 `1`보다 큰 소인수가 남아 있으면 한 번 더 반영합니다.

## 시간 복잡도

- `O(sqrt(n))`

소인수분해를 `sqrt(n)` 범위까지만 확인하므로 기본 풀이로 자주 사용됩니다.

## 실행 방법

```bash
javac phi-function/Main.java
echo 12 | java -cp phi-function Main
```

## 실행 예시

입력:

```text
12
```

출력:

```text
4
```
